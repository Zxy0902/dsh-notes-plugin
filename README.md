# dsh-client-ui-notes · DSH 笔记插件

在 DeepSeek Harness 里当**备忘录 + 目录阅读器**用：左侧栏一个「笔记」按钮，点开后
主面板变成阅读器 —— 左边文件夹树 + 置顶区，右边浏览器式标签页，Markdown 左编辑右
实时预览。

> 纯外部插件：只通过官方 Slot 机制接入，**不改动 DSH 任何源码**。

## 核心功能

| 能力 | 说明 |
|---|---|
| 目录阅读 | 任选文件夹作为根，目录懒加载；点文件即在右侧打开 |
| 标签页 | 浏览器式：切换、关闭、中键关闭、拖动排序、右键批量关闭；未保存有小圆点 |
| Markdown | 左编辑右实时预览，可分栏 / 仅编辑 / 仅预览（会被记住为默认） |
| 纯文本 | txt 单栏编辑，不显示无意义的预览栏 |
| 代码染色 | `.sql`/`.java`/`.py` 这类代码文件按语法着色，带行号；染色只是一层，照样能编辑 |
| 手动保存 | `⌘S` 或保存按钮。关闭还没保存的标签页会先问「保存并关闭 / 不保存 / 取消」 |
| 字数 | 底部状态栏显示正文字数（不计空白与换行） |
| 文档内查找 | 文档头放大镜，编辑与预览都支持；**不占用 `⌘F`**，把快捷键留给其他插件 |
| 大纲 | 长文档右侧列出目录，点一下跳过去，读到哪里哪条亮起 |
| 置顶 | 最多 6 个，可拖动排序，双栏 / 单栏切换 |
| 文件操作 | 新建、行内重命名、拖拽移动、删除（进系统回收站）、在访达中定位 |
| 状态记忆 | 标签页、置顶、展开的目录、滚动位置、未保存草稿都会保留 |
| 技能浏览 | 内置 / 自定义技能列表，可只读查看 `SKILL.md` 与它所在的文件夹 |
| agent 指令 | 查看与编辑给模型看的规则文件（如 `~/.dsh/AGENTS.md`） |
| 打开方式 | `.doc`/`.pdf` 这类不塞进编辑器，而是给出「用 XX 打开」控件 |
| 长文件名 | 被截断的名字，鼠标停一下就显示全名 |

## 安装

前置：这是**图形界面插件**，只在 Web GUI 里有界面（桌面应用，或自己跑的 `dsh web`）。
`dsh headless`、SDK 这类纯终端场景装了不会报错，但也不会有任何界面。

### 桌面应用（macOS / Windows）

左侧栏打开**「插件」面板** → 点**「添加插件」** → 填 `dsh-client-ui-notes` → 安装。

### 终端 / Linux（自建 profile）

```sh
dsh --profile notes --from-default-profile web --dump-config > /dev/null
dsh plugin --profile notes add dsh-client-ui-notes
dsh --profile notes web
```

> 第 1 步不能省：直接 `dsh plugin add` 建出来的是 base profile，**没有 Web 界面层**，
> 插件装上了也不会显示。

### 首次使用

1. 点左上角的文件夹按钮，选一个目录作为笔记根目录；
2. 文件树默认只显示「可编辑」的文本文件，想看 `.doc`/`.pdf` 就切到「全部」。

## 更新

| 方式 | 怎么用 |
|---|---|
| 插件详情页 | 侧栏「插件」→ 点本插件卡片 → 「版本」区块里点「更新」 |
| 插件市场 | 市场里搜到本插件后点「更新」 |
| 命令行 | `dsh plugin --profile <名字> add dsh-client-ui-notes@latest` |

升级入口由 DSH 自己提供，本插件不自带「检查更新」按钮。

## 兼容性

| | macOS | Windows | Linux |
|---|---|---|---|
| 桌面应用 | ✅ | ✅ | ❌ 官方未发布 |
| 自建 `dsh web` | ✅ | ✅ | ✅ |
| 删除文件 | ✅ 系统废纸篓 | ❌ 不提供 | ✅ XDG 回收站 |

**为什么 Windows 没有删除**：它没有可移植的用户态回收站，做不到「可还原的删除」，
所以干脆不显示这个入口 —— 而不是把文件挪进一个你以为是回收站的目录。

目标 DSH `>=0.2.0-rc.1`。插件零三方运行时依赖，只使用 DSH 的平台基线模块；
所有槽位注册都包在 `slots.inject()` 里 —— **DSH 未来删掉某个席位时，插件只是不显示，
不会启动失败**。
